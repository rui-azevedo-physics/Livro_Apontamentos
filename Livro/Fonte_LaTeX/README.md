# Fonte LaTeX

A fonte LaTeX de *Fundamentos de Física Estatística* não é disponibilizada
publicamente. Esta decisão procura preservar a integridade da versão autoral e
evitar a circulação de versões modificadas que possam ser confundidas com o
trabalho original.

A versão compilada pode ser consultada em
[`../Fundamentos_de_Fisica_Estatistica.pdf`](../Fundamentos_de_Fisica_Estatistica.pdf).
Os manuscritos originais e o histórico de desenvolvimento permanecem públicos
nas restantes pastas do repositório.
